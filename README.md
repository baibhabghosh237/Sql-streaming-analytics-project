# 📊 SQL Streaming Analytics Project

A lightweight product analytics project designed to practice and showcase core SQL capabilities for data-driven product management.

## 🚀 Project Overview
This project simulates a video streaming platform database to analyze content distribution, category performance, and user engagement using standard SQL queries.

## 🛠️ Database Schema & Queries
The project consists of:
- **Tables:** `users`, `videos`, and `watch_history`.
- **Key SQL Concepts Used:**
  - Filtering data with `WHERE`
  - Aggregating data with `COUNT()`, `SUM()`.
  - Grouping datasets with `GROUP BY`

## 💻 How to Analyze/Run This Code
1. Clone or download this repository.
2. Open your preferred SQL environment (e.g., SQLite Online, DB Browser for SQLite, or PostgreSQL).
3. Run the `.sql` script to create the tables, insert the sample data, and execute the product analytics queries.
